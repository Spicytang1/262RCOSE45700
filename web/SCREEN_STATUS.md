# 화면 사용 상태

## 기본 흐름에서 사용
- Login: 비동기 제공자의 감독관 목록을 인원수 제한 없이 2열·페이지 스크롤로 표시한다. 로딩·빈 목록·오류·재시도를 제공하며 숫자 키패드로 로그인한다. 현재는 기존 6명의 시연용 제공자이고 실제 조회·인증 연결은 아직 없다.
- Standby: 운행 시작·종료, 선택한 감독관의 이름·사진, 이번 회차 녹음 건수 버튼, 감독관 변경, 녹음 시작. 설정(톱니바퀴) 진입 버튼은 제거했다.
- 운행 시작마다 마이크·위치 권한을 확인한다. 이미 허용된 권한은 실제 요청을 생략하고 나머지만 요청한다. 대기의 권한 상태·‘권한 다시 확인’ 영역은 사용자 요청으로 모두 제거했다. 권한 확인 동작은 유지한다. 브라우저의 차단을 강제로 해제하거나 허용 창을 강제로 다시 띄우지는 못한다.
- 확인용 마이크는 바로 해제하고 위치 좌표는 버린다. 실제 녹음 위치는 녹음 버튼에서 별도로 받는다. 각 확인은 응답 대기를 포함해 최대 10초 기다리며, 이 동안 녹음 버튼만 비활성화한다. 운행 종료·로그아웃·다음 확인에서는 이전 응답을 무시하고 늦게 열린 마이크도 해제한다.
- Record: 실제 마이크 녹음. 4초 무음 자동 종료를 지원한다. 소리 레벨이 임계값(0.05) 미만인 상태가 4초 연속되면 기존 종료 흐름으로 녹음을 끝낸다. 첫 소리 이전의 무음은 세지 않는다. 자동 종료 후에는 대기 화면에 "무음이 4초 이어져 녹음을 자동으로 끝냈어요. 녹음은 보관했어요." 안내를 표시한다. 일반 녹음 완료 후 원본 보관이 성공하면 Standby로 복귀한다. 임계값은 실기기에서 조정해야 한다.
- App의 보관 진행·실패 화면: 완료 전에는 성공으로 표시하지 않으며, 실패 시 같은 녹음을 재시도한다. 녹음 시작 방식은 앱 녹음 버튼이면 `button`으로 저장한다.
- RecordingList: 기본은 이번 회차이며 전체 전환, 제목·메모 검색, 상태 필터, 최신·오래된순, 30건씩 더 보기. 날짜가 아닌 회차별로 묶고 회차 미지정 원본은 별도 그룹으로 유지한다. 카드에는 작은 제목 아래 네 가지 정리 항목을 크게 표시하고 각 카드에 녹음 날짜·시각·길이를 표시한다.
- RecordingDetail: 실제 원본 음성 재생·탐색, 이전·다음, 검토 상태·제목·정리 항목·메모 자동 저장. 상단 회차 줄 옆에 녹음 시작 방식을 표시한다(직접 녹음 / 수동 개입 자동 시작 / 시작 방식 기록 없음). 수동 개입 자동 시작은 차량 연동 전까지 발생하지 않는다.
- RecordingLocationMap: 정리 항목 다음, 녹음 중 차량 영상 바로 위에서 녹음 시작 시 요청한 기기 위치를 OpenStreetMap 공식 공유 지도의 핀으로 표시한다. 큰 지도 보기 링크는 제거했다. 현재 OSM 기반임을 주석으로 남겼다. 별도 키는 없고 지도 표시에 외부 인터넷 연결이 필요하다. 지도 좌표 전송 안내·출처·정확도·확인 시각을 함께 표시한다.
- RecordingVideo: 지도 아래에 "녹음 중 차량 영상" 패널을 둔다. "시연용 예시" 표시가 있고 재생 버튼은 시간만 흘린다. 실제 영상은 없으며 차량 연동 시 녹음 시각에 맞춘 영상으로 교체한다.
- 위치는 사건 위치나 차량 로그가 아니다. 예전 녹음은 위치 없음, 새 녹음의 권한 거부·시간 초과·위치 확인 불가·미지원·보안 연결 문제는 해당 사유를 표시한다. 현재 위치로 기존 녹음을 채우지 않는다.
- 정리 항목은 장소/이전 동작/대상 유형/반응 순의 선택형이며 각각 기타 직접 입력을 지원한다.
- 항목별 마지막 기타 입력은 검토 기록의 otherFieldValues에 별도로 자동 저장한다. 다른 선택지·화면으로 이동하거나 새로고침한 뒤에도 기타 재선택 시 복원한다. 기존 기타 값은 첫 전환 때 보존하며 빈 값·기본 선택지와 같은 입력도 유지한다. 목록·검색에는 현재 선택 값만 반영한다.
- 모든 녹음의 시연용 전사는 ‘직진하는데 보행자 튀어나와서 수동감속했음’, 초기 정리 예시는 직선로/직진/보행자/급감속이다. 사용자가 고친 값과 기존 수기 자료는 보존한다.
- 차량 데이터는 차선 유형·위경도·차가 하던 동작·대상 유형·횡저크·종저크·속도를 읽기 전용으로 표시한다. 모든 녹음에 같은 임시 데이터이며 각 값에 예시 표시가 있다. 예시 좌표·로그 수치는 차량 실측이나 기기 위치가 아니고 지도·원본 저장에는 사용하지 않는다. 서버 연동 TODO 주석을 유지한다.
- 녹음 검색은 제목·메모·네 정리 항목·주소·전사를 부분 일치로 찾는다. 현재 전사는 모든 녹음에 같은 예시여서 전사 단어 검색 시 다른 조건에 맞는 녹음이 모두 검색될 수 있다.
- 변경 후 350ms 대기 또는 이동 직전에 마지막 입력까지 자동 저장한다. 실패 시 입력을 유지하고 이동을 막으며 재시도한다. 새로고침·닫기 전 미보관 내용이 있으면 경고한다.
- 목록·상세는 주소에 화면 상태를 남기며 뒤로가기를 지원한다. 저장 성공 후에만 이동한다.

## 기본 흐름에서 미사용, 삭제하지 않고 보존
- Settings: 현재 감독관 이름·사진 적용과 현재 비밀번호 확인 후 숫자 4자리 변경 화면. 대기 화면에서 진입 버튼을 제거했고 라우트·코드만 남아 있다. 현재 UI에서는 진입할 수 없다.
- Review 및 ClipPlayer, Transcript: 기존 기록 확인과 음성 재생, 예시 전사·구조화 표시.
- addRecord: 기존 추가 녹음 진입과 Review 복귀 연결.
- Review의 기존 저장 버튼은 화면 복귀만 담당한다. 실제 검토·수정·저장 연결은 후속 작업이다.

## 보관과 로그인
- 녹음 원본, 감독관 고유 ID, 녹음 시작 시각, 길이, 위치 결과, 시작 방식을 IndexedDB에 누적 보관한다. 기존 보관함 구조 변경 없이 선택형 필드를 추가해 이전 원본을 보존한다.
- 위치는 녹음 버튼 클릭 시 고정밀·캐시 미사용으로 한 번 요청하며 마이크를 기다리게 하지 않는다. 권한 응답 대기를 포함해 최대 10초 상한을 둔다. 결과보다 먼저 녹음을 끝내면 원본을 메모리에 유지하고 닫기 경고와 함께 남은 시간만 기다린다.
- 취소된 위치 콜백은 무시한다. 위치 실패도 음성 보관을 막지 않으며 보관 재시도 시 최초 원본·위치를 유지한다. 상세 열기·검토 자동 저장은 위치를 다시 요청하지 않는다.
- 새로고침 후에는 감독관을 다시 선택한다. 같은 감독관의 보관 건수는 유지된다.
- 운행 시작·종료로 회차를 구분한다. 새로고침·외부 페이지 이동·닫기는 pagehide에서 종료를 시도하고 로그인 시 남은 이전 운행도 종료한 뒤 진입한다. 종료 보관 실패 시 로그인 화면에서 재시도한다. 강제 종료 순간의 처리는 보장하지 못하며 다음 로그인에서 정리할 때는 그 시각이 종료 시각이 된다. 운행 전 녹음은 불가하다.
- 목록·상세 사이 이동, 다른 탭 보기, 미보관 경고에서 이탈 취소는 운행을 유지한다. 뒤로가기 캐시로 돌아오면 감독관을 다시 선택한다. 실제 다중 기기 운행 소유권·생존 신호·만료 처리는 서버 연동 시 구현해야 한다.
- 운행 종료 후 마지막 회차 건수를 유지하고, 새 운행을 시작하면 새 회차 0건이 된다.
- 진행 중인 운행에서 감독관을 바꾸면 종료 확인을 거치며, 취소 시 기존 운행을 유지한다.
- 감독관 변경은 원본을 삭제하지 않는다. 재시도는 같은 기록 ID를 사용해 중복을 방지한다.
- 보관함은 기존 녹음을 보존하는 2판으로 확장했다. sessions는 운행 회차, reviews는 원본과 분리한 검토 기록이다.
- 기존 회차 없는 녹음은 ‘이전 녹음 · 회차 미지정’으로 표시하고 임의로 새 운행에 넣지 않는다.
- 자료는 같은 기기의 같은 브라우저·주소에 한정된다. 브라우저 자료 삭제 시 사라진다.
- 초기 공통 PIN 1234와 세션 내 변경은 시연용이다. 실제 사용자별 접근 통제나 보안 인증이 아니다.
- sessionProfiles는 이름·사진과 시연용 비밀번호 해시만 현재 탭의 sessionStorage에 보관한다. 새로고침·감독관 변경 후에도 유지되며 별도 새 세션에서는 초기화된다. 녹음·회차 자료와 별개다.
- supervisorDirectory의 list/authenticate 제공자를 실제 연결 시 교체한다. 고유 ID는 문자열·숫자를 지원하며 이름 변경은 기존 녹음과 회차의 소유자를 바꾸지 않는다. 감독관 추가·삭제 기능은 만들지 않았다.
- 기기 간 공유와 실제 전사·자동 정리는 아직 구현하지 않았다.
- analytics의 이벤트 목록·상세만 참고했고 해당 폴더는 수정하지 않았다. 요약·분석·지도·메뉴바는 가져오지 않았다.
- 4초 무음 자동 종료, 시작 방식 표시, 차량 영상 패널은 빌드와 실기기 확인 전이다.
