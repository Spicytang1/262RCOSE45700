# 녹음 대본 40선 (안전 감독관 음성 메모)

분류 라벨은 리포 `backend/app/domain/taxonomy/v1.yaml` (임시안 8종)에 맞춰 두었습니다. 카카오 입력 가이드에는 있는데 택소노미에 없는 항목(유턴, 출발, 테이크오버, 일반 감속)은 대본에 넣었고, 정답 JSON에는 `taxonomy_gaps`로 표시했습니다.

## 녹음 가이드

1. **파일 이름.** `s01.m4a`, `s02.m4a`, … `s40.m4a`. 번호는 아래 대본 번호와 같게. 폰이 wav나 mp3로만 저장되면 확장자만 바꾸면 됩니다 (`s01.wav`).
2. **기기.** 스마트폰 기본 녹음 앱으로 충분합니다. 가능하면 m4a 또는 wav. 브라우저 webm은 학교 STT가 거절하므로, 나중에 쓸 때도 wav/m4a로 변환해서 올리면 됩니다.
3. **한 대본 = 한 파일.** 시작 전에 0.5초 정도 침묵, 말이 끝난 뒤에도 잠깐 침묵을 남기세요. 한 테이크에 **5~20초**면 됩니다.
4. **말투.** 대본을 아나운서처럼 읽지 말고, 시험차 조수석에서 짧게 남기는 메모처럼 자연스럽게 말하세요. 단어가 조금 달라도 괜찮습니다. 다만 **현장 용어**(라바콘, 테이크오버, 컷인, 끼어들기, 횡단보도, 유턴, 디스인게이지먼트, 갑툭튀)와 **상대 시각**(방금, 30초 전, 아까, 1분 전 등)은 살려 주세요.
5. **환경.** 먼저 **조용한 방**에서 40개를 모두 녹음하는 것을 권장합니다. 차 안 소음은 나중에 코드로 섞을 수 있습니다. 여유 되면 차 안에서 `s01`, `s09`, `s17`, `s21`, `s36`만 추가로 찍고, 파일명은 `s01_car.m4a`처럼 `_car`를 붙이세요.
6. **어려운 대본 (s36–s40).** 말 중간에 고치거나, 사건 두 개를 한 메모에 담거나, 일부러 애매하게 말하는 항목입니다. 정정·더듬는 부분도 자연스럽게 연기해 주세요.
7. **정답.** 필드 정답은 `ground_truth.json`에 있습니다. 녹음하면서 라벨을 다시 적을 필요는 없습니다.
