## 로그인 방법
현재는 시연용 임시 감독관 계정 5개가 존재한다. 각 계정별로 고유한 코드가 부여되어있으며 초기 화면에서 그 코드를 입력해 로그인할 수 있다. 계정 추가/정보 변경/삭제 등 기능은 관리자용 기능으로, 현 화면에 작성하지 않을 계획이다. 현재 감독관 계정 5개와 로그인용 코드는 다음과 같다.

- 오퍼레이터1 operator1
- 오퍼레이터2 operator2
- 오퍼레이터3 operator3
- 오퍼레이터4 operator4
- 오퍼레이터5 operator5


  
## 현재 미사용 중인 폴더/파일들
- analytics/ , phone-preview/ ( 관리자 대시보드용 )
- web/src/screens/Review/ ( 녹음 결과 확인 페이지, App.tsx에서 import와 분기가 주석 처리됨 )
- web/src/screens/Settings/ ( 설정 화면. 대기 화면의 설정 버튼을 제거해 현재 UI에서 진입할 수 없음. 라우트 코드는 보존 )
- web/src/mockData/reviewData.ts ( 녹음 결과 확인 페이지에 사용되는 가짜 데이터 )
